# Goals

An ordinary headless package with no desktop process or MCP dependency. Named JS tools own creation and update policy, parameter schemas, descriptions and localized result captions. The public invocation SDK exposes only the current session goal and one validated staged revision per result. Node commits that revision through ADK's authoritative tool-result event; failed or cancelled scripts do not persist staged data.

Tools retain the package version captured at turn admission. Disabling, updating or removing the package affects new work; saved goal results remain readable through the common native record component. Goal records do not authorize tasks, schedule work, enforce token limits or resume closed goals.
