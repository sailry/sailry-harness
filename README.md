<h1 align="center">Sailry Harness</h1>

<p align="center">English · <a href="README.zh-CN.md">Chinese (Simplified)</a></p>

<p align="center"><strong>AI agents, files and tools in one native workspace.</strong></p>

![Sailry workspace with an English conversation and weekly plan](assets/readme/workspace.png)

Use your own models to work with files, Git, terminals, browsers, SSH and databases
beside the conversation. Add plugins to shape the workspace around your tasks.
Run locally or on your own server, and continue from Desktop or Mobile.

## Install

[Download](https://github.com/sailry/sailry-harness/releases) ·
[Changelog](CHANGELOG.md) · [Report an issue](https://github.com/sailry/sailry-harness/issues)

On macOS 13 or later, choose the DMG for Apple silicon or Intel, open it and drag
**Sailry.app** into **Applications**. Connect a model provider, then open a folder
or start a conversation.

Use Desktop's **Add Host** to install and connect to your own server.
Available platforms and packages are listed on each release page.

Sailry is still early. Features may change, and some are incomplete.
The screenshot shows an English demo workspace with illustrative content.
