# xterm2_core

The phone's terminal page runs the terminal state machine, screen and
scrollback buffers and VT parser of **xterm2_core 1.0.0** over the VT frames a
Node sends (`lib/features/terminal/emulator.dart`). Only that pure Dart core is
linked; the `xterm2` Flutter widgets are not.
