# Kenney project monsters

The 30 SVGs in `assets/icons/monsters/` are selected, hand-drawn creature
sprites from **Kenney 1-Bit Pack 1.2**, created and distributed by Kenney.

- Author and original pack: https://kenney.nl/assets/1-bit-pack
- License: Creative Commons Zero 1.0 Universal (CC0)
- License terms: https://creativecommons.org/publicdomain/zero/1.0/
- GitHub source: https://github.com/series-ai/jam-ready-assets/tree/f8206b38e4355a8b2a490e3032000d2a84883a0f/kenney-1-bit-pack/2D/misc
- Source file: `Tilesheet/monochrome-transparent_packed.png`
- Source SHA-256: `0d9abf9b812a441e1673bc166d61abb6236c0bc46b3775700bd4d4364ba170e0`

Sailry converts each selected 16×16 tile's opaque pixels into equivalent SVG
horizontal runs. Pixel placement and transparent cutouts are unchanged. SVG
`currentColor` applies the user's saved project color. No procedural avatar
generator or game code is included.

Tile coordinates below are zero-based (column, row) in the source sheet.
