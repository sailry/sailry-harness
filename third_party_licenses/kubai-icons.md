# Kubai Icons

Desktop draws package emblems with
[`github.com/yldm-tech/mygo-kubai-icons`](https://github.com/yldm-tech/mygo-kubai-icons)
v0.5.0 (commit `dca573ed4c3e3bdc321bd4995bee41115ce471e7`), an unofficial MyGo
port of [Kubai Icons](https://github.com/kubai087/kubai-icons). The module is
generated from upstream tag `kubai-icons@0.4.1`, commit
`c583030f168294d0e1926e1e7a4fbcf4ee0676ae`. It is linked unmodified; no icon
data is copied into this repository. `internal/protocol/kubai_icon_names.txt`
lists the icon ids only.
