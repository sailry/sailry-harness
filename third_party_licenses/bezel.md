# Bezel components

Source: https://github.com/crabtalk/bezel
Revision: `4a7505ab7c36aec3333d2dac45bcf4c8c600a5a5` (0.1.23)

Selected avatar, loading, thinking, Markdown/editor, material and presentation
code is adapted in `apps/desktop/src/ui`, `apps/desktop/src/content`, and the
conversation presentation. Sailry uses GPUI Kit's theme and existing interaction
owners. No Bezel runtime, fonts, icons, grammar queries or separate theme system
are bundled. The GPUI rendering fork has its own Apache-2.0 provenance notice.
