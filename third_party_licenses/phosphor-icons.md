# Phosphor Icons

Desktop draws the icons that plugins name as `phosphor:<name>` from
[Phosphor Icons](https://phosphoricons.com), fill weight. The complete fill set
of the npm package `@phosphor-icons/core` 2.1.1, 1512 icons, is embedded as the
archive `internal/desktop/icons/phosphor/fill.zip`; the `SOURCE` file beside it
records the tarball's address, its SHA-256 and how the archive is made. The
SVG files are unchanged apart from their names, which drop the `-fill` suffix.
`internal/protocol/phosphor_icon_names.txt` lists the icon names only.
