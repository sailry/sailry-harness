# ModelDial public radar data

Source: [ModelDial Radar](https://modeldial.com/radar), downloaded from
`https://modeldial.com/data/overview.json`.

Sailry downloads the public dataset at runtime without sending user data. The
data is normalized, matched to configured model identifiers and summarized for
display. No copy of the dataset is committed to this repository.
